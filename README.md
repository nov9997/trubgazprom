# АО «ТрубГазПром»

Корпоративный концепт вымышленного промышленного предприятия. Все тексты и параметры являются контентом концепта, не спецификацией реального поставщика.

## Запуск
Откройте dist/index.html в браузере или запустите локальный статический сервер из dist. Внешние библиотеки и шрифты не требуются.

## Возможности
Три категории каталога, переключение параметров, выбор продукции в запрос, раскрывающиеся блоки качества, мобильное меню, сохранение запроса КП в TXT. Серверной отправки и сбора персональных данных нет.

## Изображения
Иллюстрации (formovka, welding, loading, delivery) созданы встроенным ImageGen; оригиналы в originals, оптимизированные версии — dist/assets, промпты — work/image-prompts.json.

Реальные фотографии (21.10.2026):
- dist/assets/hero-pipes.webp — Gerd Fahrenhorst, «Rohre für Nord Stream 2 in Mukran», Wikimedia Commons, CC BY 4.0 (кадрировано);
- dist/assets/mill-inside.webp — Mostafa Gholamnejad, «Spiral Welding», Wikimedia Commons, CC0.
Атрибуция продублирована HTML-комментарием рядом с изображениями в index.html. Изображения не являются фотографиями оборудования конкретного предприятия «ТрубГазПром» — оно вымышлено.

## Развитие
Разделы можно выделить в страницы: предприятие, каталог, карточка продукции, производство, качество, поставки, контакты.
